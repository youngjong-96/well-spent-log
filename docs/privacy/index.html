잘쓸결심 개인정보처리방침

시행일: 2026년 11월 19일

잘쓸결심(이하 "앱")은 사용자의 지출 기록을 돕는 개인 가계부 앱입니다. 앱은 사용자의 개인정보를 개발자의 서버로 수집하거나 전송하지 않습니다.

1. 수집하는 정보

앱은 회원가입이나 로그인 없이 사용할 수 있으며, 개발자가 사용자의 개인정보를 수집하지 않습니다. 사용자가 직접 입력한 아래 정보는 사용자의 기기 안에만 저장됩니다.

  • 지출 기록(금액, 메모, 카테고리, 결제수단 이름, 날짜)
  • 카테고리별 예산, 결제수단 이름, 앱 설정
  • 앱 잠금을 사용하는 경우 잠금 정보(기기의 보안 저장소에 저장)

결제수단은 사용자가 정한 이름만 저장하며, 카드 번호 등 금융 정보는 입력받지 않습니다.

2. 정보의 저장과 전송

  • 모든 데이터는 사용자 기기 내부에만 저장됩니다.
  • 앱은 인터넷 권한을 사용하지 않으며, 데이터를 외부 서버로 전송하지 않습니다.
  • 광고, 분석, 추적 도구를 사용하지 않습니다.

3. 백업과 내보내기

사용자가 직접 백업 또는 내보내기(CSV 등)를 실행하면 파일이 만들어지며, 사용자가 선택한 앱이나 위치로 공유·저장됩니다. 이 파일의 보관과 공유는 사용자가 결정하며, 개발자는 해당 파일에 접근하지 않습니다.

4. 권한

  • 알림: 예산 관련 알림을 보내기 위해 사용하며, 사용자가 언제든 기기 설정에서 끌 수 있습니다.
  • 진동: 알림을 보낼 때 사용합니다.

5. 제3자 제공

앱은 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다.

6. 정보의 삭제

앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다. 사용자가 직접 내보낸 백업 파일은 사용자가 별도로 삭제해야 합니다.

7. 아동의 개인정보

앱은 아동을 대상으로 하지 않으며, 어떤 사용자에게서도 개인정보를 수집하지 않습니다.

8. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다.
